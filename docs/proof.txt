what is an fsm?
Q: set of states         # finite m states
A: set of input (0 or 1) # n distinct inputs
q0: start state # reset state
T: set of transitions
O: set of outputs        # k distinct output lines

 F = (Q,E,q0,T,O)

so proof is:

transition => P( q , a1 a2 a3 a4...an ) = (q', o1 o2 o3 ... ok)

each ai for i in (1 ,n) ai = 1 or 0
#n = num inputs

each oi for i in (1 ,k) oi = 1 or 0
#k = num outputs
