Model of FSM:
Q: set of states
A: set of n inputs
O: set of k outputs
q0: start state ∈ Q
δ: transition function
    δ(q,a) = (q',o)

a = a1, a2, a3...an
o = a1, o2, o3...ok
=> each ai and oi ∈ {0,1} 



------------------------------------------------------------------------------------------------------------------------------------
Model of sequential circuit
A: n input lines
O: k output lines
D: D-flipflops, |D| = m (m flipflops)
    Qi: output of ith flipflop
    Di: input of ith flipflop
d0 = reset state of circuit

I: (I1, I2, I3 ... Im)
    Ii ⊆ P -> Di = {t1 + t2 + t3... t | tj ∈ Ii} (Ii is the set of minterms ORed and connected to input of ith flipflop)


T: (T1, T2, T3 ... Tk)
    Ti ⊆ P -> Oi = {t1 + t2 + t3... t | tj ∈ Ti} (Ti is the set of minterms ORed and connected to ith output line)

Δ(Q,a) = (Q',o)

a = (same as defined in FSM)

Q = Q1, Q2 ... Qn (current outputs of all flopflops)

Q' = Q1' , Q2' ... Qn'
Qi' = Ii(Q,a) => value of logical expression Ii evaluated at current values of Q's and inputs.

o = o1, o2, ... ok
oi = Ti(Q,a) => value of logical expression Ti evaluated at current values of Q's and inputs.

Now the actual statement to prove:

let e be the mapping:
- e(q0) = d0
- for all q,a if δ(q,a) = (q',o)  =>  Δ( e(q), a) = ( e(q'), o)

For an FSM F = (Q,A,O,q0,δ) for all w ∈ ({0,1}^n)^*                                       (set of all possible strings of size n made of 0 or 1)
                            if δ(q,w) = (q,o)
                            (then)=> the output sequence produced by the constructed circuit is same.
