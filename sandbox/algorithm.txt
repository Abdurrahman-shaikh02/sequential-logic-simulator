			dequeue()
				run operation
		}

		Sort the S queue:
			if there is a set_port before a change_state operation on the same ff.
				then swap those two operations.

					 so trigger first then set port.)

					Then while(S queue is not empty){
						dequeue()
							run operation
					}
	}

	return
